# Advanced-java-chat-App
Real-time-multi-user desktop chat application built with java swing and socket programming.
# Technologies Used
- Java
- Java Swing
- Socket Programming
- Multithreading
- File Handling
- TCP/IP Networking
- Eclipse IDE / Apache NetBeans
- Java 10 Streams
- Client-Sever Architecture
  # Features
- Real-Time messaging
- Multi-User Chat
- Emojis Support
- File transfer
- Image sharing
- Notification sounds
- Profile avatars
- Progress bars
- GUI interface
  ## How to Run
  1. Server.java
  2. FileSever.java
  3. ChatGUI.java
